
# Portfolio - Todo Management System

## About
A Todo Management System built with Django.

## Features
- Create Tasks
- Update Tasks
- Delete Tasks
- View Tasks

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd portfolio
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
